METHOD & LIMITS

Protocol. NAB v1.1 files are split deterministically within each data category using SHA-256 file ordering. One score threshold per detector is selected on development files and then frozen for the held-out test set. The NAB time-window scoring formulation is used with the standard profile and NAB’s probationary period.

Interpretation. The reported normalized score is corpus-local and uses this project’s fixed-threshold protocol. It is not an official NAB leaderboard result, whose protocol optimizes thresholds over its evaluation corpus. Point-level precision and F1 use the labeled windows as positives; the NAB score rewards early detections and penalizes false alarms differently.

Data. The bundled NAB v1.1 series and labels are from Numenta. See the included source, license, and citation notes.
