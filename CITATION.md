# Data and benchmark citation

This repository bundles the Numenta Anomaly Benchmark (NAB) v1.1 time-series files, labels, profile definitions, and data documentation from Numenta's public repository at <https://github.com/numenta/NAB>.

Source revision used: `ea702d75cc2258d9d7dd35ca8e5e2539d71f3140`.

The upstream project is distributed under the MIT License. Its license notice is preserved in `data/nab/LICENSE.txt`. See `data/nab/SOURCE.txt` for provenance.

Please cite the benchmark paper when referring to NAB:

Ahmad, S., Lavin, A., Purdy, S., & Agha, Z. (2017). *Unsupervised real-time anomaly detection for streaming data*. Neurocomputing. https://doi.org/10.1016/j.neucom.2017.04.070
